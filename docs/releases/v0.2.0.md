# Jouzu v0.2.0 candidate

This candidate contains the post-v0.1.19 flow-control, agent-workflow, installation, and Windows launcher changes. The npm package, GitHub release, and update feeds remain unpublished until qualification is complete.

## Candidate checks

Run the repository release checks before creating an official tag:

```bash
npm run release:check
npm run test:packed
npm run test:auto-update
```

The signed Windows workflow also requires the candidate to exist in the npm registry, so it cannot prepare a v0.2.0 runtime until v0.2.0 is published or the workflow is changed to accept a local candidate archive.
