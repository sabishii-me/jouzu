# Jouzu v0.2.4

Jouzu v0.2.4 adds ACP host connections and model comparison ratings, improves first-use model selection and Shisa sign-in, and repairs the Windows launcher's web-fetch dependency packaging.

## ACP host connections

Configure an Agent Client Protocol (ACP) host to launch `jouzu acp`. The adapter drives a separate Jouzu RPC process for each session, with streamed replies and tools, persisted session loading, cancellation, model selection, and extension dialogs. Session listing and loading recognize aliases of the same working directory.

The adapter uses Jouzu's credentials, tools, extensions, and session storage. It does not add a sandbox or filesystem boundary. Automated protocol and CLI-to-RPC tests do not certify every editor's interface or native-platform behavior.

See [ACP setup and permissions](https://github.com/shisa-ai/jouzu/blob/v0.2.4/docs/acp.md).

## Models and Shisa sign-in

- Wide Models views show catalog-supplied Strength (`★`), Speed (`↯`), and Cost (`$`) ratings with one to four text symbols. Missing or invalid values show `—`. These ratings belong to the catalog offering and do not change numeric prices.
- Filtering preserves Current, Previous, Favorites, Recents, and alphabetical ordering. Rating symbols and column widths use consistent terminal measurements.
- Authenticated catalog recommendations can choose a model for an untouched first-use session. They do not override saved defaults, explicit choices, resumed sessions, or a conversation already started.
- `/login shisa` refreshes authenticated catalogs and the live model registry without a restart. Completion feedback reflects the selected model. Cancelling a refresh after credentials were saved reports that sign-in succeeded and points to `/reload`; it does not restart the cancelled work or cancel an independent user choice.

See [Models](https://github.com/shisa-ai/jouzu/blob/v0.2.4/docs/models.md), [Catalogs](https://github.com/shisa-ai/jouzu/blob/v0.2.4/docs/catalogs.md), and [Shisa sign-in](https://github.com/shisa-ai/jouzu/blob/v0.2.4/docs/shisa.md).

## Startup and terminal display

- Enable Node's optional compile cache before application imports, render help in the bootstrap, and defer unnecessary npm-root lookups. `NODE_COMPILE_CACHE` changes the cache location; `NODE_DISABLE_COMPILE_CACHE=1` disables it.
- Follow Pi's light or dark theme for Jouzu brand colors and the default code-preview syntax theme. Saved code-preview settings and `CODE_PREVIEW_THEME` keep precedence.
- Use the active locale for Labels, TextGuard review, and runtime diagnostics at startup. The exact too-small-compaction error is localized in Japanese without translating arbitrary provider details.
- Accept exact `/exit` as an alias for `/quit`, including while busy. A third-party `/exit` command keeps its meaning.

See [Configuration](https://github.com/shisa-ai/jouzu/blob/v0.2.4/docs/configuration.md) and [Tools](https://github.com/shisa-ai/jouzu/blob/v0.2.4/docs/tools.md). Japanese remains a preview.

## Reliability and Windows installation

- Keep multiloop continuation revisions current until consumption so an early history read cannot strand the next turn. Duplicate-delivery and failure safeguards remain in force.
- Preserve Gemini tool-call thought signatures through OpenAI-compatible gateways and saved-session replay. Signatures are not forwarded after switching model or provider, and legacy encrypted reasoning metadata retains its own format.
- Include the patched Defuddle diagnostics sidecar in Windows launcher runtimes. The packaging fix addresses the web-fetch extension load failure in v0.2.2 and v0.2.3 launcher installs; prepared runtimes are rejected if the required sidecar is absent. npm installations already carried the nested patched dependency.
- Handle disabled automatic-release reporting without accessing unavailable callbacks.

Install or update the CLI with:

```sh
npm install -g jouzu@0.2.4
jz doctor
```

The signed Windows x64 full installer is a separate release asset, `jouzu-win-x64-v0.2.4-setup.exe`. Its publication follows npm publication; use the version release's asset list to confirm availability.

Jouzu remains beta software. Native Windows qualification uses Windows Server 2025 and does not establish clean Windows 10/11 behavior on every configuration. ACP host interaction and terminal presentation still depend on the host and terminal in use.
