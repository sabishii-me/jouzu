# Jouzu v0.1.10

This release fixes flow-control recovery, makes rendered web content available to the model, and adds a Windows installer preview.

## Flow control and recovery

Long sessions recover automatic work after compaction, interrupted requests, and retained-history limits. Recovery preserves queued user messages and pending results. Oversized flow journals are checkpointed before loading, and `/flow reset` remains available for recoverable stuck state.

Reopening an interactive session starts with automatic turns paused. Your next message or `/flow resume` releases the pause. Inspecting `/flow` leaves it paused; background processes keep running.

Task continuations and dependency-wait decisions retain their owning work. Quiet background processes are checked through their existing process records, so a health check does not end execution tracking or discard later completion results.

Flow notifications show readable wait and result summaries. `/flow runtime` reports the loaded runtime and warns when a source rebuild requires restarting the session.

## Rendered web results

`tff-fetch_url` returns the page body to the model, capped at 50,000 characters with a truncation notice. `tff-search_web` returns the full result list. Empty searches are reported as inconclusive; reaching the requested result count is marked as possibly incomplete.

Screenshot requests default to JPEG. Images up to 1 MiB are attached to the tool result. Larger images produce a size report and instructions to lower quality or capture only the viewport.

## Windows installer preview

The per-user installer bundles Node.js/npm, Git Bash, Windows Terminal, ripgrep, fd, and Visual C++ runtime DLLs. Desktop and Start menu shortcuts open a project-folder picker and Jouzu setup, including Shisa AI sign-in.

Installation verifies the payload before activation and supports rollback to the previous version. Desktop data lives under `%LOCALAPPDATA%\JouzuDesktop\data` unless overridden. Uninstall preserves data and projects outside the installation directory. Desktop launches use installer updates rather than automatic npm updates.

The installer remains an unsigned, unpublished preview. See [Windows installer preview](../../packaging/windows/README.md) for build instructions and qualification requirements.

## Other fixes

- Stop background process trees on Windows when cancelling a task or closing a session.
- Preserve top-level reasoning-token usage reported by compatible providers.
- Explain when agents should wait for background notifications and how to coordinate task continuations with dependency waits.

## Testing limits

Live flow probes found no new session lockups or input/result-loss defects after the repairs; untested scenarios remain. Cross-turn management of another work's wait is restricted. Users can cancel a wait with `/flow cancel <token>`.

The Windows installer has native test evidence on Windows Server 2025 x64 with a 0.1.9 payload. The 0.1.10 installer needs its own complete build and acceptance run, clean Windows 10/11 qualification, and signing before distribution. Provider sign-in and microphone access need separate interactive checks.
