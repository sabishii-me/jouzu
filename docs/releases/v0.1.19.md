# Jouzu v0.1.19

Jouzu v0.1.19 upgrades the embedded Pi runtime to 1.0.0, preserves existing sessions and settings, and fixes Astra requests, content checks, and session recovery.

## Changes

- Use Pi 1.0.0 with Jouzu's existing tools, work dashboard, and regular/fullscreen interfaces. Saved interface settings are preserved.
- Keep GPT-6 Astra requests compatible with API-key and ChatGPT sign-in authentication, including prompt-cache settings.
- Prevent rejected tool-result metadata from bypassing TextGuard checks, including calls made through another tool.
- Recover interrupted flow-journal repairs without losing completed records or blocking session reopening.
- Keep the README focused on getting started, with detailed guides in the [documentation index](https://github.com/shisa-ai/jouzu/blob/v0.1.19/docs/README.md).

## Update

```bash
npm install -g jouzu@0.1.19
```

Global npm installations also update through Jouzu's updater. Existing sessions and flow records need no manual conversion.

## Limits

Live official Astra authentication and physical-terminal behavior in both display modes remain separate from fixture coverage. Pi's bundled `brace-expansion` dependency retains a known denial-of-service advisory. The Windows installer preview remains unsigned.
