# Jouzu v0.2.1

Jouzu v0.2.1 updates the embedded Pi runtime to 1.3.0, enables MCP servers, adds transcript scrollback and tmux clipboard forwarding, simplifies the Models list, and fixes flow-control recovery.

## Changes

- Use Pi 1.3.0. Saved settings, sessions, and flow records are preserved.
- Connect MCP servers with deferred tool discovery. Project MCP configuration loads only in trusted projects, and codemode stays off. See [MCP servers](https://github.com/shisa-ai/jouzu/blob/v0.2.1/docs/tools.md#mcp-servers).
- Run `/scrollback` to print the active conversation to the terminal's normal screen, search or select it with the terminal or tmux, then return to Jouzu. See [Transcript scrollback](https://github.com/shisa-ai/jouzu/blob/v0.2.1/docs/configuration.md#transcript-scrollback).
- Copy text from Jouzu inside tmux: copies go to tmux's paste buffer and are forwarded to the attached terminal's clipboard without changing your tmux configuration. See [Copying inside tmux](https://github.com/shisa-ai/jouzu/blob/v0.2.1/docs/configuration.md#copying-inside-tmux).
- Models is one ordered list with Name, Provider, and Context columns: the current model, models used earlier in the session, favorites, recent models, then everything else. Typing moves the cursor to the best match. The first `Esc` clears a search and returns to the model you were on; `↑`/`↓` move into the results with the query kept.
- The Palette opens centered in Ghostty, Kitty, WezTerm, Warp, and iTerm. Inline images are hidden while it is open and return when it closes.
- `/flow clear` releases a stuck reservation and keeps flow state. `/flow reset confirm` discards all queued messages, flow receipts, and waits, and is only for when `/flow clear` does not fix the problem. Running jobs keep running after either command.
- Prompts and automatic work continue normally after a flow reset.
- Compacted goals keep user instructions, including numbered, bulleted, and non-English ones, and leave out notifications.
- Waits no longer fail when a health check started before the wait was created, and saved sessions resume when stored messages omit unset fields.
- Web-extraction parser warnings no longer write over the terminal.

## Behavior changes

- `/flow reset` no longer changes anything by itself. In v0.2.0 it turned flow control off and on. Use `/flow clear` first, and `/flow reset confirm` only if that does not fix the problem; it discards queued messages.
- In Models, the first `Esc` clears a search instead of keeping the query.

## Update

```bash
npm install -g jouzu@0.2.1
```

Global npm installations also update through Jouzu's updater. Existing sessions and flow records need no manual conversion.

## Limits

Two transitive dependency advisories remain in the source lock: `proxy-addr` (critical) and `@modelcontextprotocol/sdk` (high), both under the bundled `pi-webaio` extension. The packaged extension removes that SDK tree, and the package check rejects it. The `brace-expansion` advisory carried in v0.2.0 no longer appears.

Physical-terminal behavior for inline-image hiding, desktop clipboard delivery through tmux, and transcript scrollback was tested with recording terminals and isolated tmux, not by hand in every terminal emulator. Live official Astra authentication remains separate from fixture coverage.

The signed Windows launcher and Jouzu update recipes are published after the npm package. The launcher carries the Jouzu version, 0.2.1.
