# Jouzu v0.2.2

Jouzu v0.2.2 adds a Japanese interface preview, independent language preferences, and session Fast mode. It also improves scrolling, child-agent defaults, recovery after provider failures, and the Windows launcher.

## Languages and interface

- Choose English or Japanese (preview) for the interface, separately from the language used for replies and requested documentation, comments, commits and reviews. First-run setup asks for interface and response languages separately.
- Open `/language` to preview and confirm preferences. Confirmed choices are saved for future sessions; a saved UI choice takes precedence over startup flags and environment variables. Choosing `Automatic` restores environment-based UI selection.
- Supported Jouzu screens, Pi settings and selectors, and built-in slash-command descriptions use the selected locale. User content and unrelated extension descriptions are preserved. Some screens need to be reopened; third-party interfaces and provider pages control their own language.
- Models, Workflow and Settings scroll on short terminals, including long forms, explanations and error messages. Workflow keeps editable agent definitions above Runs while children are active.

See [Language and prompt instructions](https://github.com/shisa-ai/jouzu/blob/v0.2.2/docs/language.md) and [Localization coverage](https://github.com/shisa-ai/jouzu/blob/v0.2.2/docs/localization.md). Japanese remains a preview; selecting a language does not guarantee model compliance or translation quality.

## Models, prompts and child agents

- `/fast on` requests priority processing for eligible GPT models over OpenAI Responses or Codex connections; `/fast off` requests standard processing. The choice is saved with the session and shown beside the model's thinking level. Provider eligibility and higher rates apply. See [Fast mode](https://github.com/shisa-ai/jouzu/blob/v0.2.2/docs/models.md#fast-mode).
- New coder and reviewer presets follow the main session's model and reasoning effort at launch and resume. Saved explicit choices remain unchanged.
- Children inherit the caller's configured response language and artifact-language policy. Running children keep their launch snapshot. Child sessions also retain the intended extension tool activation.
- Repeated instructions and task tool descriptions are shorter, and detailed Jouzu usage guidance is available as an optional reference skill. Jouzu sends prompt additions as named Pi sections, allowing updates without rewriting stable instructions on supported routes. Actual cache reuse depends on the provider.

## Recovery and fixes

- Automatic work pauses after unrecovered provider errors or output truncation, preserving pending work. Send a new message or use `/flow resume` after resolving the cause.
- Long sessions retain recoverable request-history capacity. Overlapping extension commands no longer deadlock session disposal, and commands that replace sessions work with Pi 1.4.
- Numeric tool-format settings work with Responses connections. TextGuard preserves native decoding evidence and treats command-name findings as advisory.
- Browser tools avoid an unused native HTTP import that could prevent startup on older Linux systems. Web-fetch extraction diagnostics are retained in the expandable tool result rather than printed over the interface.
- Prompt-cache refreshes are counted even when they finish after their schedule changes.

## Installation and runtime

- Upgrade the embedded Pi runtime to 1.4.0 and refresh bundled dependencies, including security fixes.
- Update the Windows launcher runtime to Node.js 24.22.1. Improve its startup and update controls, report component-preparation failures, offer recovery for outdated bundled Git, and support process locks under long state paths.
- Remove the launcher's PATH entry before uninstalling its helper.

Install or update with:

```sh
npm install -g jouzu@0.2.2
jz doctor
```

The signed Windows launcher is attached to this release. Jouzu remains beta software. Native Windows qualification uses Windows Server 2025; it does not establish clean Windows 10/11 behavior on every configuration.
